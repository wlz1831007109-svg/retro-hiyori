FORMATS

かたちから選ぶ、中国書画

掛軸だけではありません。手巻、冊頁、四条屏、横披、書法、画心など、中国書画には多様な鑑賞のかたちがあります。

掛軸・中堂

縦長に掛けて鑑賞する代表的な形式

手巻・長巻

手元で少しずつ展開して見る横長の形式

冊頁・冊屏

小画面を冊子や組物として味わう形式

四条屏・屏条

複数幅を一組として構成する装飾性の高い形式

LEARN

5分でわかる、中国書画入門

専門用語を知らなくても大丈夫。作品を見るときに役立つ基本知識を、小さな図解と一緒に紹介します。

BASIC 01

中国書画とは？

絵画・書法・詩・印がどのように一つの画面で関係するのか。

BASIC 02

肉筆と工芸品画

作品を選ぶ前に知っておきたい制作方法と表示の見方。

BASIC 03

掛軸と手巻の違い

掛けて見る絵と、手で展開して見る絵。その鑑賞文化の違い。

BASIC 04

款識・印章の見方

画面の文字と朱印から何が読み取れるのか、基本を整理します。

BASIC 05

工筆と写意

細密に描く方法と、筆意を生かす方法。対立ではなく幅として理解します。

BASIC 06

紙本と絹本

紙と絹で、墨・色・保存・見え方はどのように変わるのでしょうか。
