BEGINNER'S GUIDE

はじめての中国書画

「何を見ればいいかわからない」から始めて大丈夫です。専門用語を少しずつ知ると、作品を選ぶ基準も増えていきます。

LEARN

中国書画とは？

中国の絵画文化では、絵だけでなく、題詩・款識・書法・印章・表装までが一つの鑑賞対象になります。山水、花鳥、人物など、画題と時代の背景を一緒に見ると理解が深まります。

LEARN

肉筆作品と工芸品

Retro日和では、手描き・手書きによる作品を「肉筆」、それ以外の工芸制作による作品を「工芸品」として制作区分を明示しています。画家名の「款」は真筆保証を意味しません。

LEARN

工筆と写意

工筆は細い線や丁寧な設色を積み重ね、写意は筆勢・墨色・省略を生かして対象の意を捉えます。実際の作品には、その間に多様な表現があります。

LEARN

紙本と絹本

紙と絹では、にじみ、線の出方、色の見え方が異なります。材質は作品の表情と保存方法にも関わる重要な鑑賞ポイントです。

LEARN

款識・落款・印章

作者名、年記、詩文、題記などの款識と朱色の印章は画面の一部です。ただし、款や印があること自体は真筆を証明しません。

LEARN

山水画の人物が小さいのはなぜ？

中国山水画では、山・水・雲・樹木が大きな世界として描かれ、その中に旅人や楼閣が小さく置かれることがあります。人と自然の関係を感じる入口です。
